# 项目总结

## 起点与目标

将生活中手工记录商品保质期的步骤，整合为一次交互式 iPhone 快捷指令：获取名称、识别包装日期、计算到期日并创建 Apple 提醒事项。扫码数据库补充名称，真实包装决定日期。

## 实现与设计

工作流采用 Apple 原生快捷指令操作，条码查询使用 Open Food Facts v2 接口；包装文字通过系统图像识别提取。日期经过人工确认，再按月或天调整。提醒统一为到期日 09:00，距到期足够远时增加提前 30 天提醒。无需自建服务。

目前是用户主动运行的交互式工具，并非无人值守的后台自动化。

## 修复记录

- 修正字典返回结果、商品名称和日期的「如果」条件；原有枚举和缺失比较参数会导致“请选择每个参数的值”。采用 Mac 编辑器实际保存的「有任何值」条件（100）。
- 商品查询判断改为检查 product 对象，避免对未明确类型的 status 字典值做数字比较。
- 移除当前 Mac 版本无法识别的文字预览操作。
- 修正日期调整的单位与输入变量表示。
- 个人版本统一两处提醒列表；公开版移除设备专属列表标识，要求使用者安装时选择自己的列表。
- 以 Mac 最新修正版导出内容为公开版基础，保留 XML 源码和 JSON 快照。

## 验证情况

已完成：Mac 编辑器可保存；相关条件显示为有任何值；源码 UUID 引用与条件/菜单嵌套校验；不含个人列表标识检查；公开文件 Apple 签名。开发阶段使用公共商品条码确认 Open Food Facts 可返回商品信息。

**尚未完成 iPhone 端到端实测，不应将这些检查描述为完整功能通过。**

## 设备测试清单

- [ ] 已知商品扫码返回名称，未知商品可手动输入。
- [ ] 无网络选择直接拍照完成流程。
- [ ] 系统相机授权、拍照、OCR 成功。
- [ ] 八位日期、普通日期、多日期及无日期路径正确。
- [ ] 到期日、生产日期＋月数、生产日期＋天数均正确。
- [ ] 超过 30 天生成两条提醒，不足 30 天只生成到期提醒。
- [ ] 过期日期被拒绝。
- [ ] 提醒列表、09:00 通知与备注正确。
- [ ] 在不同系统版本、跨年和月末日期下核对计算。
